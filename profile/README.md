<h2>先看计费单位，再看数字</h2>
<p>同样写着「住宅代理」，报价可能是每条地址每月多少钱，也可能是每 GB 流量多少钱，还可能是每小时多少钱。三种计费单位对应的成本曲线完全不同，直接比数字毫无意义。有人拿按流量计费的单价去和按条计费的单价比较，得出的结论必然是错的。</p>
<p>所以看价格的第一步是确认计费单位，第二步才是比较数字。</p>

<h2>报价单里常见的加价项</h2>
<p>基础价之外，常见加价项有五类：超出并发、超出流量、指定城市或运营商、更换地址、额外端口。这五项在低价方案里往往单独收费，是账单超预期的主要来源。</p>
<p>询价时把这五项列成清单，逐条问价。不做这一步，比较的只是入场价，不是真实成本。</p>

<h3>并发限制是怎么回事</h3>
<p>并发是同时建立的连接数。有的方案限制很严，例如同时只允许少量连接。多标签浏览、多任务并行时会迅速触顶，表现为部分请求失败或排队。这个限制很少写在显眼位置，必须问。</p>
<h3>地区加价的规律</h3>
<p>主流地区通常含在基础价里，稀缺地区需要加价。加价幅度可能很高，尤其是需要指定城市或指定运营商时。业务对地区要求不严的，避开稀缺地区能省下可观成本。</p>

<h2>怎么算自己的真实月度成本</h2>
<p>步骤一，估算地址数量需求。步骤二，估算月度流量，注意把图片、视频、更新包都算进去。步骤三，估算并发峰值。步骤四，按计费单位套公式，得出基础费用。步骤五，加上可能的加价项，取一个上浮比例。</p>
<p>五步做完得到的数字，通常比直觉估算高不少。这也是为什么很多团队第一个月的账单会超预算。</p>

<h2>价格与质量的关系</h2>
<p>价格高不一定质量好，但价格明显低于同类，一定在某处打了折扣：可能是共享程度高，可能是地址历史复杂，可能是带宽被压缩，可能是支持响应慢。判断方法是看它便宜在哪一项，而不是只看便宜多少。</p>
<p>可以要求对方说明「与同类相比，你们的成本优势来自哪里」。能给出合理解释的，通常是真的有资源优势；答不上来的，多半是在资源质量上做了减法。</p>

<h2>砍价不如改条款</h2>
<p>与其在单价上磨几个百分点，不如争取三项条款：试用期延长、更换次数增加、同段追加价格锁定。这三项对长期使用的价值，通常高于折扣。尤其是第三项，业务扩张时能省下大量沟通成本。</p>
<p>如果对方坚持年付才给优惠，先按月跑一个完整周期，用实测数据谈长周期，议价空间会更大。</p>

<h2>常见问答</h2>
<h3>按流量计费一定更便宜吗</h3>
<p>只在流量很小时才便宜。一旦涉及图片、视频、大文件，流量成本会迅速超过按条计费。先算清自己的流量形态，再选计费方式。</p>
<h3>为什么有的报价不含带宽</h3>
<p>因为带宽单独计价。这类方案的基础价看起来低，实际使用时带宽费用另算。问清是否含带宽、含多少，是必做的一步。</p>
<h3>月付和年付差多少合理</h3>
<p>常见年付折扣在合理区间内。折扣过大时要警惕：可能是资源质量一般，也可能是商家需要现金流。年付前最好先月付验证。</p>
<h3>能按天买吗</h3>
<p>部分服务商支持短周期。按天买适合临时任务，单价通常更高。长期使用按天买并不划算。</p>
